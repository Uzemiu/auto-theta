读取主证据 `artifacts/slot1-playthrough/3-37.json`、现有解法、M076–M093，以及已实测世界载入口报告。未调用游戏输入，未读隐藏实现或提示，未改存档。没有进行大规模搜索。

## 结论

暂未找到比旧 202 输入更值得复现的普通关路线。新 Cat Box / Creation 不能直接补齐本关资源；最初看来有希望的 `3-X^3-37` 也被静态墙封死左下三目标。建议保留待解，不为了采集另一个初态而重跑 82 步世界运输。

## 原关的资源核对

初始 PLAYER61 位于 [4,1]，split=0；唯一叉子是 [9,1] 的 KEY60。六箱54–59，前三只 Color1、后三只 Color2。唯一 SPIKE 是 [9,5]。无 DARK、ICE、PRISM、第二叉子。普通初始分裂后两人都 split=0，因此不能把 2-21 的箱内持叉分裂直接套用，也不能凭空给 cargo 一个叉子。

六箱组成三层前 cargo + 三单箱，确实保留四对象推链，理论上能到 [9,9]，但前塔观察只有三条含 cargo 的线，四个右目标不足。四层前塔 + 两单箱只有三对象链，在推者落 [9,5] 时前体最多 [9,8]。两双塔 + 两单箱的旧实测产生四线时 cargo 已至少 [9,7]。这些是各具体构造的限制，不是全局无解证明。

同刻落刺装箱能让 cargo 变成 ghost，却不自动增加叉子。按已验证生死观测，死分支不是额外的活 cargo，因此不能把生死二分简单乘到右侧有效人数上。制造两个箱内角色后又没有外人推动，也未解决传力。

## 正规组合候选及其限制

增加第三名可自由移动角色，确实能改变算术：一个 cargo 加两个外人发生蓝箱冲突，依 M042 每支仍有 cargo 和一个外人；再三层观察可得到至多六条可用 cargo 线。它是资源结构候选，仍需真的让第三人在 3-37 区域活动。

普通 `3-37+3-X` 不应直接视为获得第三名可用推者。原 3-37 的四边 x=0、x=10、y=0、y=10 都是连续墙。已有 `3-W+3-X` 初态保留了两原图的边界墙（例如 X 平移后的 x=14 全列墙）。没有证据表明相加会替 3-37 开门。X 区的人不能仅靠 X 的边界开口穿过另一侧 3-37 的实墙。

`3-X^3-37` 的确有两个不同位置的初始人候选 [1,4]/[4,1]，X 还添加可回收的目标 [3,4] 和两箱。但联合静态墙产生明确的新阻塞：

- X 墙 [2,2] 封死 3-37 左下目标袋。原墙 [1,3]、[3,1]、左边界、底边界已经存在；目标 [1,1]/[2,1]/[1,2] 与两初始人不连通。即使完全忽略所有箱，普通四邻移动也到不了。
- X 墙 [5,6]/[6,5] 分别覆盖原 BOX54/55。真实包含/叠层属性未测，不能算作两个可正常搬运的额外资源。
- X 的非墙实体没有直接落在原 3-37 的墙上；其初始人并没有在左目标袋内。
- 静态联合图中 [1,4]、[4,1]、[9,1]、[3,4]、[9,4]、[9,9] 相互连通，但左下三目标均不在该分量。这仅检查墙，尚未把箱推移和尖刺当成可解。

因此可回收新光源与多一人的好处不能抵消左下目标隔绝。没有已验证穿墙/墙内分裂机制时，不建议优先实测叠图。
